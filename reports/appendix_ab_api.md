# Conformance audit — Appendix A (taught contracts) and Appendix B (API synopsis)

Agent G. Slice: `spec.md` 9623–9752 (Appendix A) and 9753–10068 (Appendix B), against `src/`. No Julia process started; no test suite run.

## 1. Summary

The authoring surface (Appendix B's "Authoring" block: `init_x`/`init_m`/`init_s`, `workspace`, `input_types`/`output_types`, `events`, `project`, the three assembly declarations, the bundle-name law) matches the appendix closely and in most cases literally — field for field, arity for arity. Appendix A's contracts all resolve to real code sites and the index entries point at the right place; several (guard-form detection, `shutdown!`'s tolerance of a half-built device, `map_input`/`map_output` as unenforced convention) are exact down to the mechanism.

The operator-facing surface is where this slice earns its keep. Three findings would go first:

1. **Nothing in `src/` is `export`ed or `public`ed.** Zero `export` statements, zero `public` statements, anywhere. Every name — `Simulation`, `run!`, `build`, `f`, `g`, all of it — surfaces only via `import Cadence: name` (confirmed against `test/CadenceTests.jl`'s blanket import list). Appendix A/B's language ("f and g are deliberately not exported") implies the rest *are* exported in the ordinary Julia sense; none of them are. This touches every row's "is it exported" question at once rather than each individually.

2. **`run!`'s `gui`, `pace` and `margin` keywords do not exist**, and neither does the GUI device, the greedy shipped binding Appendix B calls "the standard GUI binding," the control-plane pause primitive, or the unbounded-run start-up warning that keys off `pace = Inf`. This is not a small corner: `decisions.md` carries an extensive, ratified design for the GUI write path (D-026, D-174) and for pacing (§10.7's own decision cluster), none of which appears in `src/`. `Simulation`'s own `join_timeout` docstring still says the default is "generous for GUI teardown" — the prose outlived the feature.

3. **The `Simulation` constructor's keyword surface has drifted from the appendix in several independent ways**: `algorithm` is spelled `method` and defaults to the stepper *type* `RK4`, not an instance `RK4()`; there is an extra positional `::Type{T} = Float64` argument the appendix never mentions; there is an extra keyword `chunk_size = 16` the appendix never mentions; and `h`, `n` and `t_end` are all given literal `nothing`/`Float64` sentinel defaults in the signature rather than the literal defaults (`—`/required, `1`, `Inf`) the appendix states, with the appendix's stated behavior recovered downstream by validation rather than by the signature itself.

`linearize` (§14.10) does not exist under any spelling I tried. `ProbeDual`, named by Appendix B as "the exported canonical concrete probe scalar" and ratified by D-099, does not exist either — not in `src/`, not in `test/`. `phase_bodies` returns only the four aggregate phase blocks (`rhs`, `sweep_1`, `sweep_2`, `ticks`); the per-event guard/handler and per-component `project` callables the appendix says it also carries are not part of what it returns.

No section of this slice defeated me outright; the two absences above (`linearize`, the GUI/pacing cluster) were each confirmed by exhaustive grep rather than assumed.
