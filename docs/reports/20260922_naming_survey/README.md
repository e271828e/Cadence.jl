binding in `src/`, classified as survivor (a spec symbol), glance (used
within a few lines) or rename, with a proposed name for each rename. Six
Sonnet agents, one slice each, at tip `2844584`. The brief is
`docs/design/briefs/brief_naming_survey.md`.
