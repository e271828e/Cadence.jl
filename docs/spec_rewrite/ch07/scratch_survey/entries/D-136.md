4254	### D-136 — Unify diagnostics and liveness heartbeat into one per-writer diagnostic cell
4255	
4256	**Status.** ratified
4257	
4258	**Position.** Closing [D-133][d-133]'s [§13.2][s13-2] deferral, the runtime diagnostic stream and
4259	the liveness heartbeat get one mechanism — **one per-writer diagnostic cell**,
4260	one per rostered device plus one for the loop itself, single-writer by the same
4261	ownership argument as [§11.4][s11-4]'s staging cells (no lock, no arbitration, no new
4262	primitive), holding a **bounded ring of 16 diagnostic values plus per-kind
4263	suppressed counts** and an atomic heartbeat timestamp.
4264	
4265	**Spec.** [§7.5][s7-5], [§10.7][s10-7], [§11.1][s11-1], [§11.2][s11-2], [§11.4][s11-4], [§11.6][s11-6], [§11.8][s11-8], [§12.2][s12-2], [§12.4][s12-4], [§13.2][s13-2], [§13.5][s13-5],
4266	Appendices C/D
4267	
4268	**Rationale.** The bound **is** the rate limit — an emission past capacity
4269	within a frame is not stored and its kind's count increments, earliest-in-frame
4270	retained — which homes [§13.2][s13-2]'s "rate-limited wherever its source can repeat" as
4271	a structural property of the channel and discharges [D-133][d-133]'s deferral with no
4272	constant to tune. The loop takes each cell with `atomicswap` at the **frame-top
4273	drain**, [§11.4][s11-4]'s own point, swapping in a **shared empty sentinel** so a quiet
4274	frame allocates nothing and no load-only path goes untested; the heartbeat
4275	rides in the same cell — stored on every loop pass from inside the handle
4276	primitives ([§11.6][s11-6]), acquire-loaded at the drain, [§12.2][s12-2]'s 2 s staleness read
4277	against this field, and not a diagnostic kind. The published **framework status
4278	becomes a concrete frozen value**: per writer `recent` (this boundary's drained
4279	ring), `suppressed` (the per-kind counts the ring refused this boundary),
4280	`totals` (loop-owned cumulative per-writer × per-kind counters, *copied* into
4281	each status) and `heartbeat`, beside [§10.7][s10-7]'s pacer diagnostics — [§11.2][s11-2]'s binding
4282	rule holding **by construction**, since the swap gives the loop exclusive
4283	ownership of the batch before publication and the live accumulator is never
4284	reachable from a snapshot. Presentation is separated from channel policy:
4285	renderers print a writer × kind up to **25 cumulative occurrences** and then
4286	switch to count-only display (the `maxlog` successor), counts accumulating
4287	regardless; and the **terminal snapshot carries the final cumulative counters**
4288	([§12.4][s12-4](1), [§13.5][s13-5]), so an unattended run's complete diagnostic account survives
4289	its own shutdown. The allocation story is spec-stated: a quiet frame adds
4290	**zero heap allocation**, the per-writer status riding inline in the
4291	per-boundary snapshot allocation [§11.2][s11-2] already accepted — which requires the
4292	per-kind counters to be a **fixed-shape isbits record, never a `Dict`**,
4293	licensed by [Appendix C][sC]'s closed kind set — while a noisy frame allocates its
4294	values at emission on the writer's own task and a **fresh ring** lazily at the
4295	writer's next emission (the drained one being frozen into a snapshot and
4296	unwritable thereafter), the same GC-over-reuse trade [§11.2][s11-2] made when it rejected
4297	preallocated snapshot buffers; worst case per writer per boundary is therefore
4298	one ring of 16, everything past it an integer increment, and [§7.5][s7-5]'s scoped
4299	model-sweep zero-allocation invariant is untouched. Composition note, recorded
4300	once: `totals` is monotone across logged snapshots, so `log_every` decimation
4301	loses *which* boundary in a skipped stretch an occurrence fell on, never *how
4302	many*.
4303	
4304	**Rejected.**
4305	- *A shared queue or buffer under a lock:* cross-task contention on the loop's
4306	  own frame path and no single-writer ownership to reason from — the arbitrary
4307	  shared mutable state [§11.1][s11-1]'s two rules exist to eliminate, reintroduced for
4308	  the one structure that had escaped specification.
4309	- *A status referencing the live accumulator:* the cheapest thing to write and
4310	  a direct violation of [§11.2][s11-2]'s binding rule — a reader walking a structure its
4311	  writer is still mutating.
4312	- *Ring reuse by double-buffering:* reintroduces exactly the reader-liveness
4313	  proof the GC provides for free — [§11.2][s11-2]'s own argument against preallocated
4314	  snapshot buffers — to save an allocation incurred only on frames already
4315	  doing something unusual.
4316	- *Unbounded accumulation:* an unattended run with no status reader grows
4317	  without bound, precisely the configuration the framework must survive, and a
4318	  bound is what gives the drop policy a definition.
4319	- *A separate heartbeat channel or liveness registry:* a second cross-task
4320	  structure with the same writers, the same ownership question and the same
4321	  drain point, for one timestamp.
4322	- *A per-device rate-limit constant, [D-133][d-133]'s deferred option:* the structure
4323	  carrying the stream already bounds it — a tunable would name a policy the
4324	  channel cannot violate anyway.
4325	- *A render threshold baked into the channel:* what is recorded must not depend
4326	  on who is looking; 25 is a renderer's number.
