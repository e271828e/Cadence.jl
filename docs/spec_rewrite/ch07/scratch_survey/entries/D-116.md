3475	### D-116 — Expose `phase_bodies(sim)` as the zero-allocation invariant's measurement seam
3476	
3477	**Status.** ratified
3478	
3479	**Position.** The zero-allocation invariant's measurement seam:
3480	`phase_bodies(sim)` returns the compiled bodies of the nominal activation as
3481	named callables bound over the simulation's own buffers — the four blocks
3482	(`rhs`, `sweep_hx`, `sweep_hxu`, `ticks` taking the tick index its entries gate
3483	on) plus per-event guards/handlers and per-component `project`, keyed by the
3484	model's roster; one inspection promise: identity with the bodies the
3485	loop runs, so the in-loop argument types come by construction; CI is
3486	warm-then-assert at per-body granularity (a documented tolerance loosens
3487	exactly one assertion).
3488	
3489	**Spec.** [§7.5][s7-5], [§9.7][s9-7], [Appendix B][sB]
3490	
3491	**Rationale.** [§7.5][s7-5]'s tiers completed: guards and `project` (unconditional per
3492	boundary/frame) join the exactly-zero tier, handlers (episodic, only on firing)
3493	join the tick tier's zero-by-idiom; publication is not a phase body — the [§7.5][s7-5]
3494	carve-out made structural; isolated invocation leaves buffers valid but
3495	off-trajectory (re-`init!` to continue); the FlightCore allocation comparison in `migration_outline.md`
3496	measures through the seam.
3497	
3498	**Rejected.**
3499	- *Per-body exported functions (`rhs!(sim)`, `guard!(sim, path, name)`, …):*
3500	  five-plus exported names, an invented addressing mini-language for the
3501	  per-event callables, and hand-enumerated CI lists that go stale when a model
3502	  gains an event, where the accessor's roster is machine-enumerable.
3503	- *A no-publish advance mode on `step!`:* forks execution semantics for CI's
3504	  benefit and breaks [§10.1][s10-1]'s publication-after-every-boundary property.
3505	- *`@allocated step!` against a pinned nonzero baseline:* drifts with every
3506	  model edit, and a regression can hide inside a legitimate baseline change —
3507	  kills the canary.
3508	- *Per-component standalone tests as the invariant's discharge:* they never
3509	  call the executor, so "framework contribution exactly zero" goes unvalidated;
3510	  hand-built argument types are not the in-loop types inference sees;
3511	  composition-scale pathologies — union-splitting collapse, chunk-seam
3512	  mis-specialization — are invisible; remains a fine authoring practice for
3513	  localizing once the canary trips.
