6141	### D-173 — Fuse the discrete state letter `z` into `x`
6142	
6143	**Status.** superseded → [D-195][d-195]
6144	
6145	**Position.** The discrete state letter `z` fuses into `x`: `h_z`/`h_zu` →
6146	`h_x`/`h_xu`, `init_z` → `init_x`, `y_z` → `y_x`, bundle field `z` → `x`, `z⁺ =
6147	g(z,u,t)` → `x⁺ = g(x,u,t)`; `f`/`g` stay distinct (flow and jump maps); `m`
6148	and `Δt` keep their tier-scoped meanings; the per-function closed bundle-name
6149	sets become per-function-per-tier.
6150	
6151	**Spec.** [§3.2][s3-2], [§5.2][s5-2], [§5.3][s5-3], [§7.3][s7-3], [§8.2][s8-2], [§8.7][s8-7], [§9.3][s9-3], [§9.5][s9-5], [§13.7][s13-7], [§14.1][s14-1],
6152	[§5.3][s5-3], [§3.4][s3-4], [§8.6][s8-6], [Appendix C][sC] (all companions swept), [Appendix D][sD]
6153	
6154	**Rationale.** [D-056][d-056] untouched and central — it is what makes the fusion
6155	safe, a leaf being strictly one tier and no component reading another's state.
6156	
6157	Tier doctrine restated: stateful leaves declare tier by update law (`f` vs `g`,
6158	with `events`/`init_m`/`workspace`/`output_types`/`input_types` arities
6159	agreeing, [D-166][d-166]–[D-167][d-167]); a stateless leaf's tier is decided by its contract
6160	arities (`output_types` mandatory hence always the decider, `input_types`
6161	agreeing where declared) — no mere marker, the arity IS the tier's semantics
6162	(walking at `T` vs pinned, [D-166][d-166]–[D-167][d-167]) — and `DeclarationOnWrongTier` survives
6163	on the reduced member set while the wrong-letter error class dies with the
6164	distinction it policed.
6165	
6166	Motivation: `z` collided with the shift operator (`z⁻¹`, five spec sites —
6167	[§13.7][s13-7]'s `UnitDelay` bullet had the letter meaning two things in three lines)
6168	and was nonstandard besides — discrete state-space writes `x[k+1] = g(x[k],
6169	u[k])` and hybrid-systems notation (Goebel–Sanfelice–Teel) writes flow `ẋ =
6170	f(x)` / jump `x⁺ = g(x)` with one letter, a convention the spec already
6171	inhabited (`f`/`g`, `x⁺ = project`); the fusion halves the stage/init surface;
6172	timing deliberate — increment 3 (the discrete engine) is unbuilt, so it is
6173	written once under the fused names.
6174	
6175	**Rejected.**
6176	- *Renaming `z` to another letter:* fixes the collision only, keeps the doubled
6177	  API; every candidate letter is taken — `s` is the Laplace variable, the
6178	  mirror collision; `q` is spoken for by quaternions; `d` reads
6179	  disturbance/derivative — when every letter is taken the doubled scheme is the
6180	  problem.
6181	- *`is_discrete(::C)::Bool` trait as stateless-leaf tier decider:* derivable
6182	  hence redundant — restates what `f`/`g`, `events`, `init_m`, `workspace`
6183	  arity and `output_types` arity already fix, joining the
6184	  `DeclarationOnWrongTier` agreement set with zero new information; mandatory =
6185	  boilerplate on every leaf, defaulted = class-by-omission, which [D-039][d-039] refused
6186	  for kind; the corner it protects is rare — [§13.7][s13-7] steers stateless leaves
6187	  continuous — already netted by [§8.7][s8-7]'s rates-on-continuous error and [D-166][d-166]'s
6188	  Dual-activation CI policy, and behaviorally near-neutral under
6189	  tier-transparency; stays a cheap purely-additive retrofit if migration
6190	  falsifies the premise.
6191	- *Fusing `z` into `m` instead:* semantically tempting — discrete state is
6192	  latched memory — but it kills the method fusion, breaks the `x[k]`/`x⁺`
6193	  convention, and [§3.2][s3-2] already ruled the discrete tier's state IS its memory.
