559	### D-015 — Fused evaluation of derivatives and outputs
560	
561	**Status.** ratified
562	
563	**Position.** Fused evaluation: `f`/`h` read the fresh table (own `y`
564	included), and additionally receive state views ([D-035][d-035]); single computation
565	site for derivatives and outputs is the *rewarded* idiom, not an impossibility
566	claim.
567	
568	**Spec.** [§5.3][s5-3], [§7.4][s7-4], [§10.5][s10-5]
569	
570	**Rationale.** Recorded only through the rejections below.
571	
572	**Rejected.**
573	- *Mutable caches between `f` and outputs:* S-function/FMI style — hidden
574	  state, purity violation.
575	- *Accepting duplicate computation:* drift bug class — edited law in `f`, stale
576	  copy in `g`.
577	- *Derivative binding:* a declaration feature subsumed by `y`-access.
578	- *Orthodox `f(x,u)` + atomization as standard idiom:* 2× components/wiring for
579	  the domain-normal overlap case.
