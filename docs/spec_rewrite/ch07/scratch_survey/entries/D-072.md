2095	### D-072 — Linearization surface: three selector lists, one chunked Dual pass
2096	
2097	**Status.** ratified
2098	
2099	**Position.** The linearization surface is three selector lists —
2100	`state`/`slot`/`output`, each entry with an optional component index and a
2101	NamedTuple key that is the control-design label — validated against schema,
2102	compiled to offsets, relocatable via `at`.
2103	
2104	- The `get_*_ss`/`assign_*_ss!` shuttle layer is deleted, discharging [§7.1][s7-1].
2105	- Evaluation is one chunked Dual pass on per-invocation scratch at the operating
2106	  point, yielding exact `A`/`B`/`C`/`D` and `ẋ₀`/`y₀` simultaneously; unseeded
2107	  states stay constant, the discrete tier frozen-exact.
2108	- Linearization is a pure query — no commit, no boundary zero, no restore dance
2109	  — and its default operating point is `capture(sim)`, `capture` settled as the
2110	  full-store gather returning `(condition, t)`.
2111	- It returns labeled data, with `subsystem`/`delete_vars` as pure label-indexed
2112	  slicing.
2113	- `LinearizedSS` survives as an ordinary continuous component.
2114	- Guidance: surfaces select minimal-coordinate mechanizations, the `{NED}` rig
2115	  practice, now stated.
2116	
2117	**Spec.** [§7.1][s7-1], [§14.10][s14-10]
2118	
2119	**Rationale.** Recorded only through the rejections below.
2120	
2121	**Rejected.**
2122	- *Four `FiniteDiff` jacobians:* step-size heuristics, ~4n evaluations,
2123	  exactness lost.
2124	- *Hand-written per-variant gather/scatter structs:* ~150 lines of bookkeeping
2125	  each.
2126	- *Linearize-as-committing-service:* nothing becomes authoritative.
2127	- *Post-linearization trim restoration:* an artifact of probing the live model.
2128	- *Naive quaternion-component seeding:* off-manifold; the coordinate choice is
2129	  the surface author's.
