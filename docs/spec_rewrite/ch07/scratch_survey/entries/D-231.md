8559	### D-231 — Require isbits store values, checked at build
8560	
8561	**Status.** ratified
8562	
8563	**Position.** Every field of a store value — a discrete leaf's `s`, and any
8564	leaf's `m` — is isbits or a `Symbol`, and Stratum A checks every
8565	`init_s`/`init_m` field, reporting `IllegalStoreField`. The frozen-reference
8566	latitude of [§4.1][s4-1] stays with signals. A PRNG object is workspace; the values
8567	that determine its next draw are the state.
8568	
8569	**Spec.** [§3.2][s3-2], [§7.3][s7-3], [§8.2][s8-2], [§9.1][s9-1], [Appendix C][sC], [Appendix D][sD]
8570	
8571	**Rationale.** The three sources disagreed and the code checked nothing:
8572	[§7.3][s7-3] granted `s` "any immutable value" under the frozen-reference rule, the
8573	declaration's docstring and [D-195][d-195] said isbits, and the build enforced neither.
8574	Isbits is one exact predicate, `isbitstype`, checkable once at build.
8575	"Immutable plus frozen references" is a claim about the run and can only be
8576	contract, which contradicts [§7.3][s7-3]'s own opening — stores governed by checks,
8577	the workspace by contract. Every discrete-state use in the grounding is
8578	counters, enums, filter taps, timers and RNG words. The latitude was earned by
8579	field handles on ports ([§4.4][s4-4]), and bulk data does not change between ticks, so
8580	its home is the component instance. Isbits makes "snapshots are free" literal,
8581	gives a future on-disk trace one fixed layout per store, and retires the
8582	`deepcopy` hedges the implementation had placed around store capture and
8583	replay. The RNG example never needed type freedom: the generator is mutable
8584	and could never be a store value, and its state values are isbits. Measured on
8585	Julia 1.12, rematerializing a `Xoshiro` from its values each tick allocates
8586	under `randn`, whose out-of-line tail lets the object escape, and not under
8587	`rand`; a workspace-resident generator loaded by field assignment allocates
8588	under neither. The spec blesses the latter and stays silent on the generator's
8589	internals, which are the stdlib's. `Symbol` is admitted because it is not
8590	isbits in Julia yet loses nothing the rule was written for: interned,
8591	immutable and never freed, it copies as a pointer to permanent data, reads
8592	safely from any thread and serializes as its name. It is also how Julia code
8593	writes a label, where `@enum` puts every instance name into the module
8594	namespace, a cost that compounds across a component library. The check stays
8595	one exact predicate per field and does not recurse, so a struct nesting a
8596	`Symbol` is rejected.
8597	
8598	**Rejected.**
8599	- *Any immutable value under the frozen-reference rule (the prior [§7.3][s7-3] text):*
8600	  uncheckable, so contract-only; motivated by an example that does not need
8601	  it; leaves the copy hedges in place.
8602	- *Isbits as contract, without a check:* the predicate is exact and one line;
8603	  a rule that can be checked and is not is the workspace's regime applied to
8604	  state.
8605	- *Rematerializing the generator per tick:* allocation depends on which
8606	  sampler is called, a property no spec should lean on.
8607	- *Naming the generator's word count in the spec:* stdlib internals; the
8608	  principle — mutable object in `ws`, its state values in `s` — survives a
8609	  field added or removed.
8610	- *Strict isbits, modes as enums:* the spec's own examples say enums and
8611	  would have needed no change, but the rule would forbid the `Symbol` idiom
8612	  for every author to buy a "self-contained bytes" claim nothing yet consumes.
