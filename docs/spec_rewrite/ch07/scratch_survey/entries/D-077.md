2261	### D-077 — Allocate workspace via a per-activation `workspace` method
2262	
2263	**Status.** ratified
2264	
2265	**Position.** Workspace by allocation: `workspace(::C, ::Type{T})` (continuous)
2266	/ `workspace(::C)` (discrete) — the method *is* the allocator, called per
2267	activation and per scratch-store set.
2268	
2269	**Spec.** [§7.3][s7-3], [§8.1][s8-1], [§8.2][s8-2], [§9.1][s9-1], [§9.3][s9-3]
2270	
2271	**Rationale.** Sizes from the instance, eltypes from the activation; `undef`
2272	construction the recommended idiom; availability on both tiers (continuous
2273	scratch joins the `T`-generic surface, generic in-place fallbacks under
2274	`Dual`); scoped debug poison (`NaN` on float eltypes, `typemin` on integer
2275	eltypes, element types with no sentinel skipped and the skip reported once per
2276	activation) and no-information-between-calls contract.
2277	
2278	Annotation (2026-09-24): the allocator takes the scalar on both tiers, the
2279	discrete side always receiving `Float64`, so its arity is no longer a tier
2280	fact; the rejection of `similar`-based re-scalaring is what keeps the scalar
2281	in the signature at all ([D-263][d-263]).
2282	
2283	**Rejected.**
2284	- *Concrete-nominal allocation + framework `similar`-based re-scalaring
2285	  ([D-079][d-079]-style):* no schema stake here; reconstruction cannot cover non-array
2286	  scratch (plans, factorizations, index buffers); authors legitimately allocate
2287	  scalar-dependent structure (`Dual` chunk-width buffers).
2288	- *Superseded position — `init_workspace` by value (earlier design of record):*
2289	  a workspace is not memory that conditions overlay, and no [§8.2][s8-2] by-value
2290	  argument (condition overlay base, probe-value barrier) covers a store
2291	  conditions exclude and the poison overwrites.
2292	- *`workspace_type` returning types with framework instantiation:* array types
2293	  carry no dimensions; runtime sizes like `kf.n` invisible to any zero-arg
2294	  constructor; size-in-type-parameters lands on the `MMatrix` codegen
2295	  catastrophe.
2296	- *Keeping the discrete-only restriction:* an asymmetry without a principle;
2297	  the multiplicity of continuous calls is the poison check's case, not
2298	  prohibition's.
