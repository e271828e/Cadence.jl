925	### D-029 — Input trace on by default
926	
927	**Status.** ratified
928	
929	**Position.** Input trace on by default, cleared at `init!`, plain kill switch.
930	
931	**Spec.** [§11.2][s11-2], [§11.5][s11-5], [Appendix B][sB]
932	
933	**Rationale.** Recorded only through the rejections below.
934	
935	**Rejected.**
936	- *Opt-in:* the trace is primary data — the log is recomputable from it, never
937	  the reverse; the session you need replayed is the one you didn't plan to
938	  record.
939	- *Tying trace to the log switch:* conflates primary and derived recording.
940	- *Rolling window/sampling:* complexity without a customer.
