2541	### D-086 — Compile the executor's schedule into unrolled statically-typed entries
2542	
2543	**Status.** ratified
2544	
2545	**Position.** The compiled executor ([§9.7][s9-7]): schedule data compiled per
2546	activation into a concretely-typed entry tuple over statically typed storage,
2547	walked by compile-time unrolling — [§7.5][s7-5]/[§9.5][s9-5]/[§5.1][s5-1] are reachable only under
2548	full specialization.
2549	
2550	**Spec.** [§5.1][s5-1], [§7.5][s7-5], [§9.5][s9-5], [§9.7][s9-7]
2551	
2552	**Rationale.** Phase bodies as the semantically forced outer decomposition
2553	(order-free `h_x`/`f`/`g` blocks, topo-ordered `h_xu` block, event callables —
2554	seams cost nothing; parallel-evaluation and incremental-recompile doors
2555	recorded); chunking behind statically-typed function barriers bounds compile
2556	cost (superlinear → linear, measured; chunk size the only representation
2557	freedom); mitigation ladder = lazy activations, reduced opt-level for
2558	non-nominal activations, precompile-workload caching (TTFX a CI artifact);
2559	views rebuild-per-call (hoisting = compiler CSE, whose legality condition is
2560	the staleness rule); schedule tuples constructed type-opaquely, consumed only
2561	by the walk.
2562	
2563	Annotation (2026-10-02): amended by [D-289][d-289]. [D-289][d-289] restates the compile-cost
2564	figures and the mitigation ladder, and the ladder drops the reduced
2565	optimizer level for non-nominal activations. The rejection of type-erased
2566	call tables stands, now measured.
2567	
2568	**Rejected.**
2569	- *Vector-of-abstract entries:* per-entry dynamic dispatch boxes stage returns
2570	  — kills [§7.5][s7-5] and its canary role, unfolds [§9.5][s9-5]'s check; union splitting
2571	  rescues only toy scale and cannot close an open method set.
2572	- *Type-erased call tables (`FunctionWrapper`-style):* same specialization
2573	  count as chunk-of-one with extra machinery, no cross-entry inlining/SROA,
2574	  a relied-on seam on internal ABI — the [D-017][d-017] lesson.
2575	- *Framework-maintained view hoisting:* manual cache-invalidation duty for
2576	  loads the compiler hoists exactly where legal; mis-scoping = silent
2577	  stale-state reads.
