7279	### D-203 — The termination record carries typed sources and the tail residue
7280	
7281	**Status.** ratified
7282	
7283	**Position.** The run's termination record is a three-field value — the final
7284	boundary time, absent when no boundary ever ran; a typed source; the tail
7285	residue — and this amends [D-201][d-201]'s disposal clause: the run's-end sweep folds
7286	the residue into the record *and* presents it through the logging backend,
7287	still never published. The bundled rulings:
7288	
7289	- The sources follow the diagnostic kind convention — kind is identity,
7290	  payload plain data ([§13.2][s13-2]) — without joining [Appendix C][sC]'s diagnostic set:
7291	  `EndTimeReached` (no payload), `ModelRequestedStop` (the holding face),
7292	  `ControlRequestedStop` (its issuer), and `LoopError` (the propagated
7293	  cause). The record covers `errored` exactly as it covers `stopped` ([§13.6][s13-6]).
7294	- The operator interrupt stays a tag on an ordinary stop ([§13.5][s13-5]): the
7295	  `:interrupt` issuer arm of `ControlRequestedStop`, never a fifth kind.
7296	- The control-plane stop word carries its issuer — the requesting device,
7297	  `:code`, or `:interrupt` — written by compare-and-swap from empty,
7298	  first writer wins ([§12.1][s12-1]).
7299	- `DeviceJoinTimeout` becomes an ordinary structured kind: written to the
7300	  loop's own cell in tail step (5), collected by the run's-end sweep
7301	  ([§12.4][s12-4], [Appendix C][sC]).
7302	- Source consultation order is normative: a pending control stop at frame
7303	  top, then `t_end`, then the stop faces at each publication — the recorded
7304	  source of a boundary where two hold is the first in that order.
7305	- `init!` clears the record with the trajectory ([§12.6][s12-6]).
7306	
7307	**Spec.** [§11.8][s11-8], [§12.1][s12-1], [§12.4][s12-4], [§12.6][s12-6], [§13.5][s13-5], [§13.6][s13-6], [Appendix C][sC]
7308	
7309	**Rationale.** [D-201][d-201] disposed of the tail window's diagnostics through
7310	presentation because the termination record did not yet exist as machinery;
7311	with it on the bench, presentation-only fails the unattended run — [§11.8][s11-8]'s own
7312	audience for the terminal counters. Once `run!` returns, "did a device hang
7313	the join?" was answerable only by whoever captured the log stream, and a
7314	harness exercising the abandonment path had to scrape logs. The record is
7315	none of [D-201][d-201]'s three rejected disposals, which all stand: it is not a
7316	publication — it follows no boundary sequence and sits on no data plane — it
7317	is not cell retention across runs (`init!` clears it with the trajectory), and
7318	it is not a drop. It is stopped-sim state on the diagnostic-observation side
7319	of [§13.5][s13-5]'s own doctrine, and the precedent of carrying failure detail was
7320	already spent when the abnormal path put the cause exception in the record.
7321	The typed sources apply [§13.2][s13-2]'s convention to the outcome channel, dissolving
7322	a flat record whose `exception` field applied only to the error case and
7323	whose `face` field only to the stop-face case; construction simplifies with
7324	them, the loop returning a source where it detects one and the record
7325	assembled once, in the outermost `finally`, after the sweep has the residue
7326	in hand. Issuer attribution is nearly free: every stop site knows its
7327	identity — the handle carries the device name, the interrupt is caught at a
7328	known unmask point — and the anonymous `Bool` was discarding it at the moment
7329	of writing; first-CAS-wins matches the first-`true` doctrine for stop faces
7330	and names the request that actually initiated the tail. The residue stays
7331	bounded by construction: one final ring take per writer, at most sixteen
7332	entries plus suppressed counts. The record's cost is nil on any path that
7333	matters — it is built once per run, on the cold side of the final snapshot.
7334	
7335	**Rejected.**
7336	- *Superseded position — presentation-only disposal ([D-201][d-201]):* honest but
7337	  ephemeral; the tail's facts evaporated from the program at the moment it
7338	  regained control. [D-201][d-201]'s rejected list never weighed the record, which
7339	  had not been built when it was adjudicated.
7340	- *A fifth source kind for the interrupt:* [§13.5][s13-5] rules the interrupt a tag on
7341	  an ordinary stop — nothing failed; a consumer that cares matches on the
7342	  issuer, and a distinct type would quietly reverse a settled ruling for no
7343	  gain.
7344	- *A flat record with `nothing`-padded per-source fields (the prototype's
7345	  first cut):* the shape [§13.2][s13-2] rejects for diagnostics — most fields
7346	  meaningless for most sources, tests matching on a `Symbol` instead of a
7347	  type.
7348	- *`Float64` time with `NaN` for "no boundary ever ran":* time is generic —
7349	  the clock is seeded `zero(T)` ([§7.2][s7-2]) — and `NaN` is an in-band sentinel of
7350	  the species [D-202][d-202] rejects; absence spelled out-of-band instead.
7351	- *Carrying the configured `t_end` in `EndTimeReached`'s payload:* the
7352	  effective policy already lives in the run metadata ([§11.5][s11-5], [§13.5][s13-5]); a second
7353	  home for a fact that has one.
7354	- *Termination sources as [Appendix C][sC] diagnostics:* the record is outcome, not
7355	  warning — three of the four sources are healthy ends, and the interrupt
7356	  sentence in [§13.5][s13-5] already ruled the appendix gains nothing here.
