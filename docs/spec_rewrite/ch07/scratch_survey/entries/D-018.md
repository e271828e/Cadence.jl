646	**Status.** ratified

648	**Position.** Tier-2 localization: lazy cubic Hermite dense output + bracketed
649	derivative-free root-finding (ITP/Brent) on guard probes that run the sweep;

661	**Rationale.** Recorded only through the rejections below.

663	**Rejected.**
