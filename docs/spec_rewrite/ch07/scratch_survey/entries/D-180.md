6456	### D-180 — Bank per-event `direction` as an unbuilt guarded addition
6457	
6458	**Status.** ratified
6459	
6460	**Position.** Per-event `direction` (`:upward`/`:downward`/`:both`) is recorded
6461	as a guarded addition, unbuilt.
6462	
6463	**Spec.** [§2.1][s2-1]
6464	
6465	**Rationale.** `:downward` is pure sign-flip sugar (desugars to the negated
6466	predicate); `:both` (fire on any predicate change) costs little machinery —
6467	compile-folded edge test, direction-blind root-finder, endpoint policy
6468	generalizing to the post-edge endpoint — but serves only the shared-handler use
6469	case, and the domain's transitions are asymmetric-handler pairs ([D-082][d-082]:
6470	hysteresis wants two events anyway); strong precedent exists (MATLAB events
6471	`direction = 0`, Simulink either-direction zero-crossings, Modelica both-edge
6472	relation events), so it is banked until migration shows demand.
6473	
6474	**Rejected.**
6475	- *Building it now:* machinery cheap but no grounded use case; [§2.1][s2-1]'s
6476	  negated-guard second event covers every current need.
6477	- *Rejecting it permanently:* the precedent is universal and the analysis shows
6478	  no structural obstacle.
