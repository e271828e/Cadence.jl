7078	### D-196 — Rename the phase-body sweeps to stage-numbered names
7079	
7080	**Status.** ratified
7081	
7082	**Position.** The phase-body roster's sweep blocks rename `sweep_hx` →
7083	`sweep_1` and `sweep_hxu` → `sweep_2`; arities, entry sets and the roster's
7084	other members (`rhs`, `ticks`) are untouched.
7085	
7086	**Spec.** [§9.7][s9-7], [Appendix B][sB], [Appendix D][sD]
7087	
7088	**Rationale.** Post-[D-195][d-195] the `hx`/`hxu` spellings read as
7089	continuous-tier-only, but each sweep is a genuinely tier-mixed body — one
7090	block whose entries mix `h_x`/`h_s`, the other `h_xu`/`h_su`. The stage number
7091	is the tier-neutral fact ([§5.3][s5-3]), so the names state it.
7092	
7093	**Rejected.**
7094	- *Keeping the fused spellings:* quietly re-fuses the letter [D-195][d-195] split, in
7095	  the one place a reader meets both tiers inside a single compiled block.
7096	- *Per-tier sweep pairs (`sweep_hx` + `sweep_hs`):* would split the execution
7097	  structure to serve a name — the single topologically-ordered body per stage
7098	  is the design.
