5672	### D-165 — Split output-stage returns into public `y` and private `w`
5673	
5674	**Status.** superseded → [D-194][d-194]
5675	
5676	**Position.** Every output stage returns either `y::NamedTuple` (ports only) or
5677	`(y, w)::Tuple{NamedTuple, NamedTuple}`; a `nothing` in either slot is a probe
5678	error; an empty `y = (;)` is legal, so port-less stages fall out of the general
5679	law (stages are discovered by method existence, membership is a partition of
5680	declared ports that may be empty) — a stage producing neither ports nor `w` is
5681	a dead-stage build error (`DeadStage`).
5682	
5683	**Spec.** [§5.2][s5-2], [§5.4][s5-4], [§7.5][s7-5], [§11.2][s11-2], [§8.3][s8-3], [§9.5][s9-5], [§9.7][s9-7], [§13.2][s13-2], [§14.4][s14-4]
5684	
5685	**Rationale.** `w` carries the component's private intermediates: an
5686	`isbits`-leaf NamedTuple, never a table cell.
5687	
5688	**One-hop law**: `h_x`'s `w` flows to `h_xu` if defined, otherwise to the
5689	downstream set (`f`, guards, handlers); `h_xu`'s `w` flows to the downstream
5690	set; nothing flows implicitly — forwarding across hops is an explicit re-return
5691	(`(y, (; w..., extra))`). Symmetric on the discrete tier (`h_z` → `h_zu` →
5692	`g`), stated once.
5693	
5694	`w` joins the closed bundle name sets of `h_xu`, `f`, guards, handlers, `h_zu`,
5695	`g`; presence in a bundle follows the producing stage's probed return (bare-`y`
5696	producer ⇒ no `w` key ⇒ the [§13.2][s13-2] framing diagnostic on a consumer that
5697	destructures it).
5698	
5699	`w` is **SSA-passed inside fused executor passes** (the step fuses sweep + `f`;
5700	each event round fuses sweep + guards + fired handlers) and never persisted —
5701	freshness by construction, recomputation cost zero, and the executor commits to
5702	round-fusion as a design constraint.
5703	
5704	`w` types are probe-observed; the probe validates the NamedTuple form and
5705	consumer reads against the observed field set (did-you-mean from actual fields,
5706	weaker than declaration-backed but located).
5707	
5708	`w` joins the branch-shape rule and the **always-on check at the nominal
5709	activation**: expected = the nominal probe's observed type, one baked `isa`
5710	beside the `y` test — folds to zero instructions when stable, and converts the
5711	unintended-branch-divergence class (which otherwise surfaces only as
5712	allocations in testing) into a loud, located, field-naming error at first
5713	divergent execution, with blame text honestly citing the probe ("expected what
5714	the nominal probe observed"), complementing [§7.5][s7-5]'s canary (detection) with
5715	localization.
5716	
5717	**Non-nominal activations run no `w` check**: with no declaration for a
5718	branch-independent anchor and no store to embed into, a strict probe-observed
5719	check there false-positives on the legal constant-branch idiom
5720	(probe-branch-dependent expectations — the one-probe-point argument), while
5721	correctness needs no guard (a `Float64` in `w` under `Dual` is an honest
5722	zero-partial constant by the embedding guarantee; downstream promotion is
5723	exact).
5724	
5725	`local_types` is deleted with its satellites: stage membership derives over
5726	`output_types` alone; `ContractNameCollision` retired; `UndeclaredReturnField`
5727	candidates = `output_types`; `get_local` retired from the [§14.4][s14-4] selector family
5728	and [§11.2][s11-2]'s read bindings — the inspection path for intermediates is
5729	*promote to output* (FlightCore precedent: intermediates were only ever
5730	inspected by inclusion in the `Model` output); local cells leave the [§9.7][s9-7]
5731	store; [§8.3][s8-3] visibility becomes: declared in `output_types` = public, returned
5732	in `w` = private **by construction** (nothing to connect, list or filter);
5733	walkthrough 5 rewritten.
5734	
5735	Guidance, not law: a `w`-only `h_x` is redundant when `h_xu` exists (fold it in
5736	— both run once per sweep); it is the honest spelling of `u`-independent shared
5737	intermediates when no `h_xu` exists.
5738	
5739	**Rejected.**
5740	- *Walking the nominal-observed type to synthesize non-nominal expectations:*
5741	  rejected as machinery kept alive for a check that catches nothing the nominal
5742	  one misses.
5743	- *`local_types` status quo ([D-034][d-034]/[D-055][d-055]):* declaration + table cells +
5744	  presentational filtering for values that were never interface; threading is
5745	  structurally private and cheaper, and per-activation probe observation
5746	  dissolves the dropped-partials objection that rightly killed observation
5747	  authority for *pinned* locals.
5748	- *Pass-through on bare `y`:* the one implicit flow in the design, plus a
5749	  bare-`y`-vs-`(y, nothing)` subtlety needing a didactic paragraph.
5750	- *The `(y, nothing)` chain-terminate form:* no demonstrated customer; extra
5751	  fields downstream are harmless to a destructuring consumer.
5752	- *Opaque `isbits` `w`:* no name-shaped diagnostics.
5753	- *Persisted `w` slots / table cells for `w`:* a cell needs a fixed
5754	  per-activation type, and with `local_types` gone there are only bad sources —
5755	  probe-observed types detonate branch-dependently, the
5756	  `output_types`-inference flaw re-imported; a declaration resurrects what is
5757	  being deleted; an anchor+walk keeps the output-side walk alive for private
5758	  values. SSA-passing dissolves the question: a flowing value has no type
5759	  contract to violate, promotion handles mixed branches exactly — this is what
5760	  makes probe-observation sound here where [D-034][d-034]/[D-055][d-055] rightly rejected it for
5761	  cells. Also: staleness class, store traffic for register-resident values, `w`
5762	  names re-entering the cell namespace, and the loss of "every cell is a
5763	  connectable port". The forfeited snapshot visibility is covered by
5764	  promote-to-output, with a debug-mode SSA capture recorded as the cell-free
5765	  door.
5766	- *Restricting port-less stages to `h_xu`:* the one-hop law routes a sole
5767	  `h_x`'s `w` directly downstream; with no `h_xu` defined, port-less `h_x` is
5768	  the spelling whose no-`u` view set honestly declares the intermediates
5769	  `u`-independent.
