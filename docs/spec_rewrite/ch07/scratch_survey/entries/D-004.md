376	### D-004 — Immutable value signals in a typed signal table
377	
378	**Status.** ratified
379	
380	**Position.** Immutable value signals in a typed signal table.
381	
382	**Spec.** [§4.1][s4-1]
383	
384	**Rationale.** Recorded only through the rejections below.
385	
386	**Rejected.**
387	- *Shared mutable buffers:* aliasing/staleness, concurrent-read hazards.
388	- *Mixed semantics:* second thing to document/test.
389	- *A monolithic per-component `y` struct:* freshness is per-struct, so it can
390	  be half-fresh mid-sweep with no way for a reader to tell — per-cell freshness
391	  is tied to the producer's schedule position.
