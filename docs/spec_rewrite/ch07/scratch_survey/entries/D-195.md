7022	### D-195 — Give the discrete state its own letter `s`
7023	
7024	**Status.** ratified
7025	
7026	**Position.** The discrete state un-fuses from `x` into its own letter `s`;
7027	[D-173][d-173]'s `z` retirement stands untouched — bare `z` still means only the shift
7028	operator `z⁻¹`.
7029	
7030	- The discrete-tier names re-split: `h_x`/`h_xu` → `h_s`/`h_su`, `init_x` →
7031	  `init_s`, `y_x` → `y_s`, bundle field `x` → `s`, `x⁺ = g(x,u,t)` → `s⁺ =
7032	  g(s,u,t)`; the continuous tier keeps the `x` family, and `f`/`g`, `m` and
7033	  `Δt` keep their meanings.
7034	- The per-function-per-tier closed bundle-name sets become per-function closed
7035	  sets again: the two tiers' name families are disjoint by construction.
7036	- The wrong-letter error class [D-173][d-173] retired rejoins
7037	  `DeclarationOnWrongTier`'s member set — a discrete leaf declaring `h_x`, or
7038	  a continuous one declaring `h_s`, is statically diagnosable again.
7039	
7040	**Spec.** [§3.2][s3-2], [§5.2][s5-2], [§5.3][s5-3], [§7.3][s7-3], [§8.2][s8-2], [§8.7][s8-7], [§9.3][s9-3], [§9.5][s9-5], [§12.5][s12-5], [§13.7][s13-7], [§14.1][s14-1], [§3.4][s3-4], [§8.6][s8-6],
7041	[Appendix A][sA], [Appendix B][sB], [Appendix C][sC], [Appendix D][sD] (all companions swept)
7042	
7043	**Rationale.** [D-173][d-173] correctly retired `z` but recycled the continuous letter,
7044	erasing a real distinction: the discrete state is a different object — no
7045	derivative, any isbits type (pinned, eltype-generic or mixed), latched between
7046	ticks, stored in per-component state stores where the continuous state lives in
7047	the flat buffer ([§9.4][s9-4]) — and one letter made leaf declarations and framework
7048	prose read as one mechanism where the engine holds two.
7049	
7050	[D-173][d-173]'s "every candidate letter is taken" premise has since emptied for `s`:
7051	the Laplace variable appears nowhere in the spec — the document's only
7052	transform-domain symbol is `z⁻¹` — and `s` carries unique positive precedent,
7053	being legacy FlightCore's own discrete state field (`Model.s`), which [§12.5][s12-5]'s
7054	consumer survey already quotes as `x`/`s`; the migration (`migration_outline.md`) reads the legacy
7055	vocabulary back rather than introducing a third letter. The "doubled API"
7056	objection is nominal, not per-leaf: a leaf is strictly one tier ([D-056][d-056]) and
7057	still implements exactly one name family, and the doubling buys back the
7058	wrong-letter diagnostic. The hybrid-systems `x⁺` convention [D-173][d-173] leaned on
7059	models a single state that both flows and jumps; the framework's tiers are
7060	disjoint ([D-056][d-056], [§3.2][s3-2]), so its premise never applied here. [D-173][d-173]'s
7061	`is_discrete` rejection is untouched — the arity-is-the-tier doctrine survives
7062	with the letters split.
7063	
7064	**Rejected.**
7065	- *`w`:* free in current text since [D-194][d-194], but permanently means intermediates
7066	  in the log's lineage ([D-165][d-165], [D-169][d-169], [D-194][d-194]) — reuse would make one letter
7067	  mean two things across the log's history; reads as process noise/disturbance
7068	  in the state-space literature; prefix near-miss with the `ws` workspace
7069	  field.
7070	- *`d`:* `D` is already the compiled sample-rate divisor ([§8.7][s8-7], [Appendix D][sD]) and
7071	  the feedthrough matrix in `linearize`'s return, `d` the trim decision vector
7072	  ([§14.7][s14-7]); differential-operator reading, flagged by [D-173][d-173] already.
7073	- *Keeping the fusion:* the collision argument that motivated it was against
7074	  `z`, not for `x` — with a clean letter available, the shared letter's only
7075	  remaining yield is the halved name count, which per-tier disjointness makes a
7076	  diagnostic asset instead.
