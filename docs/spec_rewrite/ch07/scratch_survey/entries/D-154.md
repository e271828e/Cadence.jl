5343	### D-154 — Remove per-event re-decode; serialize same-component events
5344	
5345	**Status.** ratified
5346	
5347	**Position.** **The per-event re-decode is removed — the signal table is
5348	written only by sweeps — and a component fires at most one event per round**,
5349	declaration order picking among its simultaneously-eligible events (guards stay
5350	evaluated every round for [D-153][d-153]'s samples; the firing step is what's capped;
5351	once-per-event-per-boundary and the quiescence iteration unchanged, so
5352	multi-event components keep full within-boundary expressiveness, serialized
5353	across rounds). The single epoch rule follows: **a handler executes against
5354	exactly the world its guard fired on** — own `y`, foreign `u` and own `x`/`m`
5355	are all the firing round's sweep, so `y = h(x)` holds at every handler entry
5356	(f.5's incoherence dissolved by deletion where [D-152][d-152] dissolved it by addition),
5357	a blocked event is re-decided next round against the post-transition sweep
5358	(fire-on-falsified-premise gone), and cross-component handler order is
5359	unobservable with no delivering mechanism (nothing writes mid-round).
5360	
5361	**Spec.** [§5.3][s5-3], [§10.4][s10-4], [§10.6][s10-6]
5362	
5363	**Rationale.** A round-5 kernel dry-run finding (finding 10), resolved by
5364	redesign after re-examining the within-round visibility rule it implements —
5365	supersedes [D-016][d-016]'s per-event re-decode, its [D-152][d-152] auto-publish amendment, and
5366	[D-100][d-100]'s pre-materialization mechanism ([D-100][d-100]'s round-start-`u` *semantics*
5367	survives, now by construction). The natural single-pass executor is correct:
5368	f.10's staging pass, carrier and `u`/`y` split are mooted and "no shadow table,
5369	no allocation" becomes trivially true; cost = one extra intra-boundary sweep
5370	per serialized same-component event, rare and microseconds.
