4207	### D-135 — Scope the activation cache to immutable compiled artifacts, keyed on the Build
4208	
4209	**Status.** ratified
4210	
4211	**Position.** Amending [D-052][d-052], the activation cache is scoped to **immutable
4212	compiled artifacts** — layouts, compiled plans, the validated flag — keyed by
4213	concrete scalar type and living on the **`Build`**, since an activation is a
4214	pure function of the build and the scalar ([§9.4][s9-4]'s own words).
4215	
4216	**Spec.** [§7.5][s7-5], [§11.1][s11-1], [§9.2][s9-2], [§9.4][s9-4], [§14.8][s14-8]
4217	
4218	**Rationale.** **Every buffer set has exactly one owner**: the `Simulation`
4219	owns its nominal activation's buffers, materialized from the cached layouts at
4220	construction and what the loop's zero-allocation stepping runs on; every
4221	service invocation owns the scratch set it instantiates from those same layouts
4222	— [§14.8][s14-8]'s per-invocation rule promoted from a trim-local statement to the
4223	general one, [D-070][d-070] being the decision that forced it (iterating on shared
4224	buffers aliases the sim's authoritative stores, warn-but-assign reborn). The
4225	envelope-grid sweep's amortization is restated honestly: what the cache saves
4226	is probe re-runs, layout construction and Julia's compilation of the `Dual`
4227	chain — never buffer reuse, the per-point working-store allocation being
4228	O(model size) and trivial against the solve it feeds, and [§7.5][s7-5]'s
4229	zero-allocation invariant being scoped to the stepping loop (the services were
4230	always allocation-tolerant, [§14.8][s14-8]). Two consequences stated where they belong:
4231	the `Build` is an **immutable artifact that may back any number of
4232	`Simulation`s, concurrently** ([§9.2][s9-2] — true by construction once buffers are
4233	single-owner, which is what [§9.2][s9-2]'s `Simulation(build::Build; …)` factorization
4234	plus [§11.1][s11-1]'s inline-`run!` parallel sweeps were already inviting), and **lazy
4235	materialization is torn-state-free under concurrent first requests** as a
4236	normative guarantee, mechanism unspecified (a guard around insertion suffices,
4237	at service time and never on the hot path; purity makes the worst benign race
4238	duplicated work). Recommended idiom for [§11.1][s11-1]'s parallel sweeps,
4239	recorded at both sites: pre-materialize with the existing `build(world;
4240	activations = …)` keyword and the shared artifact is fully immutable, with no
4241	synchronization on any path.
4242	
4243	**Rejected.**
4244	- *Cached shared buffers:* [D-070][d-070]'s aliasing — warn-but-assign reborn — and it
4245	  makes the `Build` mutable in exactly the way multi-`Simulation` sharing
4246	  forbids.
4247	- *Per-`Simulation` activation caches:* defeats the sharing [§9.2][s9-2]'s artifact
4248	  factorization bought: every worker re-probes and re-compiles.
4249	- *Requiring explicit pre-materialization for any concurrent use:* turns a
4250	  safety property into a user obligation — the guard is cheap and off the hot
4251	  path, and a sweep that forgets the keyword would get corruption rather than a
4252	  slower first request.
