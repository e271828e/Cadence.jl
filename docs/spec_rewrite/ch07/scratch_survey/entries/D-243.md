9067	### D-243 — Classify `Symbol` as an opaque port leaf
9068	
9069	**Status.** ratified
9070	
9071	**Position.** The port walk treats a `Symbol` as one opaque leaf: stored
9072	whole in a cell of its own eltype, accepted by identity, never descended.
9073	Julia's `ismutabletype(Symbol)` does not make it a mutable type for [D-237][d-237]'s
9074	refusal. A `Symbol` surfacing as a root input is refused like a handle, since
9075	it has no synthesis.
9076	
9077	**Spec.** [§4.3][s4-3], [§7.3][s7-3], [Appendix C][sC]
9078	
9079	**Rationale.** [§4.1][s4-1] requires of a port value immutability plus frozen
9080	references, and [§7.3][s7-3] admits a `Symbol` in a store because it is interned,
9081	immutable and never freed. A `Symbol` therefore meets the table's requirement
9082	on the grounds the store already accepts. [D-237][d-237] refuses mutable types to rule
9083	out aliasing, and no API mutates a `Symbol`; the refusal the walk raised was
9084	an artifact of Julia's classification, not of the design's reasoning. The
9085	cost of the refusal was concrete: the idiomatic mode label is a `Symbol`, so a
9086	mode so labelled could not be declared public, and [§7.5][s7-5]'s remedy for the
9087	absent event stream worked for enum modes alone. The classification is by
9088	[D-237][d-237]'s existing rule with one exemption, so the store shape, the identity
9089	acceptance and the outermost-type rule all carry unchanged. A struct nesting
9090	a `Symbol` is non-isbits and immutable, hence one opaque leaf as a whole,
9091	which mirrors [§7.3][s7-3]'s ruling that a struct nesting a `Symbol` is not a store
9092	field. A `Symbol` root input has no first instance and no zero, so the
9093	handle's refusal covers it.
9094	
9095	**Rejected.**
9096	- *Keeping the refusal and making `Symbol` store-only:* the argument that
9097	  admits it at the store is denied at the table, and [§7.5][s7-5]'s remedy stays
9098	  halved.
9099	- *A scalar-like leaf with `Symbol("")` as its synthesis:* a meaningless
9100	  default the probe would feed to a stage; the empty symbol is no instance an
9101	  author means.
