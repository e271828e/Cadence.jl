5608	### D-163 — Ban `==` for separately-compiled float comparisons
5609	
5610	**Status.** ratified
5611	
5612	**Position.** **Float outputs are compared leaf-wise with a tolerance, never
5613	`==`, wherever the two sides are separately compiled** — the executor contracts
5614	`a*b - c*d` into an FMA where a differently-compiled reference (a type-unstable
5615	evaluator, a hand-rolled per-component check, today's FlightCore path in `migration_outline.md`'s
5616	comparison) does not, and along a dependency chain the last-ulp difference
5617	accumulates.
5618	
5619	**Spec.** [§6.2][s6-2], [§7.5][s7-5]
5620	
5621	**Rationale.** Increment-1 observation promoted to doctrine; measured in
5622	`prototypes/cellstore_bench`'s `check.jl`, same class as the main line's
5623	3945596. Two consequences past test hygiene: [§9.7][s9-7]'s chunk size remains a
5624	genuine implementation freedom only while no test asserts bit-exactness across
5625	chunk sizes, and the FlightCore value comparison in `migration_outline.md` is a tolerance comparison by
5626	construction, not by concession. Determinism is untouched — within one build
5627	the schedule is fixed and [§6.2][s6-2] made every sum an ordered junction entry, so a
5628	run reproduces itself bit-for-bit.
5629	
5630	**Rejected.**
5631	- *Bit-exact assertions under a `muladd`-free or pinned-math build:* buys a
5632	  brittle equality by giving up the codegen [§7.5][s7-5]'s invariant depends on.
5633	- *Per-test ad-hoc tolerances:* precisely what stating it once as doctrine
5634	  prevents.
