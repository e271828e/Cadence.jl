2204	### D-075 — Name flow/update/output stages by letter and dependence class
2205	
2206	**Status.** ratified
2207	
2208	**Position.** Letters and stage names: `f` = continuous flow, `g` = discrete
2209	update, `h_x`/`h_xu` (continuous) and `h_z`/`h_zu` (discrete) = output stages
2210	with products `y_x`/`y_xu`/`y_z`/`y_zu` — the hybrid-systems flow/jump pair
2211	(Goebel–Sanfelice–Teel) joined to the control/estimation `y = h(x, u)`
2212	convention.
2213	
2214	**Spec.** [§5.3][s5-3]
2215	
2216	**Rationale.** Bare `h` = step size only (double booking retired); suffix = the
2217	*dependence class* (state-only vs state-plus-input — `y = h(x)` vs `y = h(x,
2218	u)` in the name; modes fold under the state letter, ambient `t`/`Δt`/`ws`
2219	unnamed); the tier pairs mirror exactly (`x`/`xu` ↔ `z`/`zu`); declaration on
2220	the wrong tier = build error (`DeclarationOnWrongTier` — widened from stage
2221	names to all tier markers, `events` included, [D-112][d-112]); three-level narrowing
2222	taught (stage name ⊇ bundle ⊇ destructured reads).
2223	
2224	**Rejected.**
2225	- *`h` for the discrete update:* collides with the step size; forfeits the
2226	  jump-map alignment.
2227	- *`g` for outputs:* the complementary collision.
2228	- *`h_xm`/`h_xmu` letter-exhaustive suffixes:* traded for tier symmetry and the
2229	  textbook mirror — the suffix's job is the feedthrough split, not an argument
2230	  inventory.
2231	- *Verb names (`decode`/`compute`):* encode nothing.
2232	- *`Moore`/`Mealy`:* exact, opaque.
2233	- *A tier-neutral stage pair:* no honest neutral state letter; tier-distinct
2234	  names double as cheap drift checks. Superseded on this point by [D-173][d-173] —
2235	  fusing the discrete state into `x` supplies the honest neutral state letter
2236	  whose absence was the rejection's whole ground, and the drift-check value
2237	  dies with the distinction it policed.
2238	- *The earlier `g_s1`/`g_s2` stage spelling:* numbered stages name a schedule
2239	  position, not a dependence class, and leave `h` double-booked.
