2167	### D-074 — Hand off component-function arguments as one named bundle
2168	
2169	**Status.** ratified
2170	
2171	**Position.** Named-bundle hand-off: every component function is `fn(comp,
2172	args)` — one NamedTuple bundle of zero-copy views, destructured by name in the
2173	signature; `project(comp, x)` alone stays positional.
2174	
2175	**Spec.** [§5.2][s5-2], [§11.4][s11-4]
2176	
2177	**Rationale.** The bundle law (a field exists iff the store or tier fact
2178	exists: undeclared stores absent, never `nothing`-filled; `t` everywhere, `Δt`
2179	discrete-only, `ws` iff `workspace` declared); closed per-function-kind name
2180	sets, growth = a decision-log event; probe failures carry did-you-mean against
2181	the legal set, synthesized from a `FieldError` (structured: type + field as
2182	data, Julia ≥ 1.12) matched against the bundle's own NamedTuple type — no
2183	message-text scraping, the bundle staying a bare NamedTuple, a getproperty
2184	wrapper the recorded fallback.
2185	
2186	**Rejected.**
2187	- *Positional signatures + a clock-view type:* dead slots written unread,
2188	  un-droppable mid-list holes; the view type subsumed by naming.
2189	- *Keyword arguments via `Base.kwarg_decl` reflection:* a relied-on seam on an
2190	  internal binding — the [D-017][d-017] `task_local_storage` lesson.
2191	- *Keyword + `_...` slurp:* permanent noise; "signature = read-set" weakens to
2192	  "at least".
2193	- *One context object carrying workspace too:* grab-bag accretion; mutable
2194	  member muddies the immutable-views teaching.
2195	- *Time as a wired `Clock` component:* time is ambient in `f`/output
2196	  stages/guards/handlers — two access idioms for one quantity.
2197	- *`nothing`/`(;)` padding for undeclared stores:* defers the error from
2198	  destructuring to first field access, with a worse message.
2199	- *A `comp.Δt` virtual property:* [D-019][d-019] — the period is a schedule-position
2200	  fact, and `===`-identical siblings may sit under different `rates` keys.
2201	- *Positional signatures, additionally:* leave the `t`/`Δt` scalar pair
2202	  swappable without any error, both being bare same-typed reals.
