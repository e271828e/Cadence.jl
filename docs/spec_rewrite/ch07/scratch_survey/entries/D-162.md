5570	### D-162 — Adopt per-eltype homogeneous cell stores over per-instance
5571	
5572	**Status.** ratified
5573	
5574	**Position.** **C2 adopted — per-eltype homogeneous cell stores: cells
5575	flattened by [§7.1][s7-1]'s leaf walk into one contiguous buffer per element type,
5576	build-time offsets carried in entry fields, the port type in the address
5577	token's parameter** ([§9.7][s9-7] amended).
5578	
5579	**Spec.** [§7.1][s7-1], [§9.7][s9-7]
5580	
5581	**Rationale.** Kernel prototype increment 1 — the parked f.3 cell-store
5582	representation bench (`prototypes/cellstore_bench`, 2026-08-08; Apple Silicon,
5583	Julia 1.12.6, chunk 16, one cold process per point). Gate 1 (mandatory) tied —
5584	both candidates zero-allocation, sweep and snapshot, at every N. Gate 2 decided
5585	it: C1's cold sweep compile ran 0.60 s → 56.2 s over N = 1 → 400 identical
5586	instances, visibly superlinear (15.7 s at N = 200), against C2's 0.64 s → 1.14
5587	s — flat, the code sharing real, confirmed structurally by
5588	compiled-MethodInstance counts at N = 100 (C2: 4 `run!`, 3 `gather`, 3
5589	`scatter!`; C1: 103/105/306), which also closes the parked const-prop risk:
5590	offsets are not propagated as constants across the measurement's `@constprop
5591	:none` barrier, which is the real loop's condition. On the 8-partial `Dual`
5592	activation the ratio narrows (3.5× at N = 200) but the shape is what counts:
5593	C2's compile *saturates* at ~9 s from N ≈ 50, bounded by chunk-type count
5594	rather than model size — which demotes [§9.7][s9-7]'s mitigation ladder to optional —
5595	while C1's climbs unbounded (0.83 → 35.1 s at N = 200, still rising). Gate 3
5596	followed: C2's per-entry sweep cost is flat (~7.1 ns nominal, ~48 ns Dual)
5597	where C1's degrades (5.0 → 48.9 ns nominal, 17.9 → 85 ns Dual — 403 distinct
5598	bodies plus a pointer chase per gather); snapshot runtime ties (~1130 ns at N =
5599	400, zero-alloc both).
