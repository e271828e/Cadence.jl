7706: ### D-215 — Extend Appendix C with the kinds the prototype raised
7707: 
7708: **Status.** ratified
7709: 
7710: **Position.** Seven kinds join [Appendix C][sC]'s closed set, and two vocabularies widen.
7711: 
7712: - Build, collected: `ChildNameCollision` (a bare container key against the
7713:   `sample_times` sugar or a sibling field, or two children with one name),
7714:   `TransparentContainerUnknown`, `TierUnreadable` (the tier twin of
7715:   `ClassUnreadable`), `IllegalPortType` (the port twin of `IllegalStateLeaf`).
7716: - Service, fail-fast: `ArgumentInvalid` (the twin of `DeploymentInvalid` for
7717:   arguments that are not deployment parameters — `step!`'s, `trim!`'s,
7718:   `TableBinding`'s, a period constructor's), `ReadSetMisuse` (the read
7719:   side's twin of `ConditionNodeMisuse`), `NotAttached` (`detach!`'s mirror
7720:   of `AlreadyAttached`).
7721: - `UnknownPort`'s wire end admits `connection`, an interface-connection entry's
7722:   internal side ([D-210][d-210]); `EventHalfMissing`'s reason admits an entry that is
7723:   not an `Event`.
7724: - Internal invariant checks are not diagnostics: they raise a distinct
7725:   `InternalInvariant` exception outside the kind set.
7726: 
7727: **Spec.** [§13.2][s13-2], [Appendix C][sC]
7728: 
7729: **Rationale.** Surfaced by the site inventory for the prototype increment
7730: retiring its string stand-in: 31 of its 144 refusal sites matched no [Appendix C][sC]
7731: row, and [Appendix C][sC] makes adding a kind a decision-log entry. Most are
7732: behaviors the log already rules without naming the kind — [D-210][d-210]'s empty route,
7733: [D-211][d-211]'s and [D-212][d-212]'s child-name collisions — or twins of existing kinds on
7734: another axis: class versus tier, state leaf versus port type, condition node
7735: versus read selector, attach versus detach. The argument checks share one kind
7736: because they share one payload shape — the call, the argument, the value, the
7737: constraint — exactly as the deployment parameters share `DeploymentInvalid`.
7738: An internal invariant has no fix for the user to be told; a kind for it would
7739: put an unreachable check into the acceptance-test contract.
7740: 
7741: **Rejected.**
7742: - *A kind per argument check (`StepArgumentInvalid`, `TableBindingInvalid`,
7743:   …):* the row count grows with the API surface while the payload shape stays
7744:   identical.
7745: - *Folding `TierUnreadable` into `ClassUnreadable`:* a different axis —
7746:   primitive-versus-assembly against continuous-versus-discrete — with a
7747:   different list-in-hand.
7748: - *Internal invariants as a kind:* a diagnostic states the user's fix; an
7749:   invariant has none, and its row would be an untestable contract.
7750: - *Leaving the unmapped sites as message-only errors:* the string stand-in
7751:   reintroduced inside the increment retiring it.
