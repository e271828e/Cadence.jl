5587: ### D-164 — Reject components that declare nothing and define no stage
5588: 
5589: **Status.** ratified
5590: 
5591: **Position.** A component that declares nothing and defines no stage is a build
5592: error; the authoring rule is that declarations live at module top level. An
5593: increment-2 finding, extending [§8.1][s8-1].
5594: 
5595: **Spec.** [§8.1][s8-1]
5596: 
5597: **Rationale.** **Declarations written in a local scope silently do not exist**
5598: — inside a `let`, a function body or a `@testset`, `h_x(::MyComp, (; x)) = …`
5599: binds a new *local* function rather than adding a method to the global `h_x`,
5600: so calls inside the block resolve correctly while the build, dispatching on the
5601: generic function, sees a component that declares nothing and proceeds. The
5602: local-scope sibling of [§8.1][s8-1]'s `using Cadence` trap, and worse-behaved: the
5603: existing shadowing check cannot reach it, there being no parent-module binding
5604: to compare against — the shadow is a local binding that vanishes with its
5605: block. Mitigation adopted at the other end: an inert component is unwritable on
5606: purpose, which costs a line and catches the misspelled-declaration family too.
5607: Found the hard way in the kernel prototype's early `check.jl`, since retired
5608: into `test/`, where fixture components defined inside their own testset made
5609: the probe's own rejection tests pass vacuously; diagnosed first as a world-age
5610: effect and disproved by direct test (a method defined in a function body *is*
5611: visible to that body's later calls — the shadowing is what bites).
5612: 
5613: **Rejected.**
5614: - *Documenting the caveat only:* the failure is silent and its symptom — an
5615:   inert component — is exactly what the check names.
5616: - *A world-age-style check comparing `which(...).primary_world` against the
5617:   caller's world:* measures a mechanism that turned out not to be the cause.
