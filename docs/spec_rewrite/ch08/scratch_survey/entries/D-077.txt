2224: ### D-077 — Allocate workspace via a per-activation `workspace` method
2225: 
2226: **Status.** ratified
2227: 
2228: **Position.** Workspace by allocation: `workspace(::C, ::Type{T})` (continuous)
2229: / `workspace(::C)` (discrete) — the method *is* the allocator, called per
2230: activation and per scratch-store set.
2231: 
2232: **Spec.** [§7.3][s7-3], [§8.1][s8-1], [§8.2][s8-2], [§9.1][s9-1], [§9.3][s9-3]
2233: 
2234: **Rationale.** Sizes from the instance, eltypes from the activation; `undef`
2235: construction the recommended idiom; availability on both tiers (continuous
2236: scratch joins the `T`-generic surface, generic in-place fallbacks under
2237: `Dual`); scoped debug poison (`NaN` on float eltypes, `typemin` on integer
2238: eltypes, element types with no sentinel skipped and the skip reported once per
2239: activation) and no-information-between-calls contract.
2240: 
2241: Annotation (2026-09-24): the allocator takes the scalar on both tiers, the
2242: discrete side always receiving `Float64`, so its arity is no longer a tier
2243: fact; the rejection of `similar`-based re-scalaring is what keeps the scalar
2244: in the signature at all ([D-263][d-263]).
2245: 
2246: **Rejected.**
2247: - *Concrete-nominal allocation + framework `similar`-based re-scalaring
2248:   ([D-079][d-079]-style):* no schema stake here; reconstruction cannot cover non-array
2249:   scratch (plans, factorizations, index buffers); authors legitimately allocate
2250:   scalar-dependent structure (`Dual` chunk-width buffers).
2251: - *Superseded position — `init_workspace` by value (earlier design of record):*
2252:   a workspace is not memory that conditions overlay, and no [§8.2][s8-2] by-value
2253:   argument (condition overlay base, probe-value barrier) covers a store
2254:   conditions exclude and the poison overwrites.
2255: - *`workspace_type` returning types with framework instantiation:* array types
2256:   carry no dimensions; runtime sizes like `kf.n` invisible to any zero-arg
2257:   constructor; size-in-type-parameters lands on the `MMatrix` codegen
2258:   catastrophe.
2259: - *Keeping the discrete-only restriction:* an asymmetry without a principle;
2260:   the multiplicity of continuous calls is the poison check's case, not
2261:   prohibition's.
