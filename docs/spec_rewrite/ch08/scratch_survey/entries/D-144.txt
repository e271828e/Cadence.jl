4797: ### D-144 — Rename the computed-exports helper `faces` to `passthrough`
4798: 
4799: **Status.** ratified
4800: 
4801: **Position.** The computed-exports helper is renamed `faces` → `passthrough`;
4802: keyword arguments (`prefix`, `sep`, `except`, `only`) and semantics are
4803: unchanged. [§11.6][s11-6]'s `faces(b)` claim-set declaration is deliberately untouched:
4804: the rename dissolves the overload rather than propagating it, leaving the
4805: device-binding declaration sole owner of the name. The rename is the first
4806: application of the four-class naming convention now recorded in [§8.1][s8-1] as the
4807: exported-name audit's criterion: (1) declarations (author defines, framework calls) are
4808: bare nouns or `init_*`/`_types` — `connections`, `exports`, `events`,
4809: `input_types`, `output_types`, `local_types`, `init_x`/`init_z`/`init_m`,
4810: `workspace`, `probe_value`, the stages `h_x`/`h_xu`/`h_z`/`h_zu`, `f`, `g`,
4811: `project`, and `faces(b)`; (2) value selectors called against `reads` and
4812: snapshots carry `get_` — `get_state`, `get_deriv`, `get_output`, `get_local`,
4813: `get_slot`, `get_face` ([§14.4][s14-4]); (3) lifecycle and mutating actions are verbs,
4814: `!` when they mutate — `build`, `run!`, `step!`, `replay!`, `init!`, `attach!`,
4815: `detach!`, `shutdown!`, `apply!`; (4) build primitives ([§13.3][s13-3],
4816: framework/tooling-facing) are plain verbs — `resolve`, `resolve_terminal`. A
4817: name in the wrong class is a rename candidate on that ground alone. Two
4818: residuals are flagged and deferred to the exported-name audit in `pending.md`, not renamed now:
4819: `input_faces`/`output_faces` (noun accessors punning on the `_types`
4820: declarations, mitigated by being framework-facing rather than daily authoring
4821: surface) and `workspace` (a declaration whose bare noun reads as an accessor —
4822: borderline, every rename candidate clunkier, lean keep).
4823: 
4824: **Spec.** [§11.6][s11-6], [§8.1][s8-1], [§8.6][s8-6], [§8.8][s8-8], [§9.1][s9-1], [§13.3][s13-3], [§13.7][s13-7], [§14.4][s14-4], Appendix
4825: B (swept)
4826: 
4827: **Rationale.** Two ambiguity axes motivated it: the helper wore the declaration
4828: class — a bare noun like `connections`, `exports`, `events`, `input_types`,
4829: `workspace`, things an author defines and never calls — while actually being a
4830: helper the author calls inside an `exports` body; and it collided with
4831: `get_face`, the value selector, so "faces" named both a selection of values and
4832: a generation of export pairs. `passthrough` names the helper's purpose in
4833: [§8.8][s8-8]'s own words ("the helper exists for the pass-through case, where an
4834: assembly hands a child's unfed requirements up one level"), reads as an
4835: operation rather than a declaration, and stays accurate if [§8.8][s8-8]'s guarded
4836: output-direction addition ever lands.
4837: 
4838: Annotation (2026-09-25): class 1 reads from [D-267][d-267] as a noun phrase naming what the declaration returns, prefixed by the bundle field it defines where one exists; the four classes stand.
4839: 
4840: **Rejected.**
4841: - *`get_children_faces`:* `get_` is reserved for value selectors, so the name
4842:   would deepen the `get_face` collision it is meant to fix; the plural also
4843:   misstates the signature — the helper takes exactly one child — and what it
4844:   returns is labeled export pairs, not faces.
4845: - *`reexport`:* false — a leaf's input faces were declared, never previously
4846:   exported, so there is nothing to re-export — the word would only be honest
4847:   for the assembly-child case.
4848: - *`child_faces`:* fixes plurality alone, keeping both ambiguity axes — still a
4849:   bare noun in the declaration class, still colliding with `get_face`.
4850: - *Renaming `input_faces`/`output_faces` or `workspace` in the same pass:*
4851:   audit-time calls whose cost lands when the real export surface exists;
4852:   deciding them now would settle by anticipation what the exported-name audit exists to settle
4853:   against the migrated code.
