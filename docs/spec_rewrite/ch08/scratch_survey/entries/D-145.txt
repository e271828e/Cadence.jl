4855: ### D-145 — Deduplicate pass-through `except` lists with a shared feed-list idiom
4856: 
4857: **Status.** ratified
4858: 
4859: **Position.** Pass-through exports duplicate the wiring list at every generic
4860: seam — every level of the real tree is a generic seam, so each pilot- and
4861: environment-facing input surfaces through four `exports` declarations
4862: (`Systems` → `Vehicle` → `Aircraft` → `SimpleWorld`), and because `passthrough`
4863: is inputs-only and re-exporting a fed face is a two-producers error, each call
4864: carries an `except` tuple restating by name the wire list in the same
4865: assembly's `connections`. No new vocabulary and no framework change: [§8.8][s8-8]
4866: gains a worked shared-feed-list idiom beside the two-entry-`except` `World`
4867: example — the author writes one constant, the feed list mapping the actuator
4868: child's output faces to destination child faces, and both declarations compute
4869: their share of it (`connections` maps the list into wires; each `passthrough`
4870: call takes its `except` set from a small `fed_faces(feeds, child)` projection),
4871: [§8.5][s8-5]'s blessing of declaration bodies as ordinary code doing the work.
4872: 
4873: **Spec.** [§8.1][s8-1], [§8.4][s8-4], [§8.5][s8-5], [§8.8][s8-8], [§14.6][s14-6]
4874: 
4875: **Rationale.** [D-043][d-043] is reaffirmed, not reopened, by this finding, which closes
4876: the round-4 dry-run report. The drift is caught loudly — the design working —
4877: but the duplication is [§8.1][s8-1]'s and [D-039][d-039]'s "structure kept in two artifacts"
4878: (~10 names at `Systems`, everything `c172.jl:697-713`'s `assign!` writes).
4879: Doctrine recorded with it: adding a channel is one edit (the pair
4880: simultaneously creates the wire and removes the face from the export surface),
4881: the two declarations cannot drift because neither holds the shared names — the
4882: drift class is removed, not merely detected — and every existing error stays
4883: loud (a misspelled destination is an unknown-face error with the child's face
4884: list in hand, whether the wire or the `except` entry meets it first); one
4885: honest asymmetry: a pair omitted from the list is not an error but a legible
4886: structural change — the face joins the export surface, ultimately a root slot
4887: for conditions to cover ([§14.6][s14-6]) — what the idiom preserves and the rejected
4888: helper surrenders is that the feed statement exists to be reviewed, an omission
4889: being legible in one authored artifact rather than defined away as the
4890: complement of the wire list. The gap being closed was pedagogical, not
4891: semantic: the section's only example hand-wrote a two-entry `except`, reading
4892: as though the duplication stays small, when at C172X scale it is four
4893: hand-synchronized name lists.
4894: 
4895: **Rejected.**
4896: - *A framework helper deriving `except` from `connections`* (`except = fed(s,
4897:   "aero")` reading the assembly's own wire list): auto-bubbling on [D-043][d-043]'s
4898:   exact ground — the author's explicit statement of which faces are fed
4899:   disappears, so a forgotten wire stops being a build-time unconnected-input
4900:   error and becomes a silent promotion of that face to a live root slot, caught
4901:   at best later as an `UninitializedSlots` deployment error of misleading
4902:   shape, at worst not at all once a GUI or condition writes it — [§8.4][s8-4]'s
4903:   walkthrough 2 inverted; the single source must be authored data, never
4904:   inferred structure.
4905: - *Wildcard-export vocabulary:* [D-043][d-043] stands — ordinary code suffices, and this
4906:   row is the demonstration that was missing.
4907: - *Doing nothing:* the status quo prices the idiom's absence at four
4908:   hand-synchronized lists per generic seam chain, a measured migration-day cost
4909:   rather than a hypothetical one.
