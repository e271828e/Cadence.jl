5981: 
5982: **Status.** ratified
5983: 
5984: **Position.** Assembly routing declarations renamed and split: `connections` →
5985: **`child_connections`** (strictly child-port → child-port, keeps the
5986: mandatory-even-empty assembly kind-marker role); `exports` **splits by
5987: direction** into **`input_connections`** (face => internal input path or
5988: tuple-of-paths fan-out; entry spelling unchanged) and **`output_connections`**
5989: (internal source path => face, now flow-ordered); direction is *declared by the
5990: method*, [D-041][d-041]'s endpoint derivation becoming a cross-check with a sharper
5991: error and the mixed-entry class inexpressible; face-name uniqueness spans both
5992: boundary declarations; one invariant spans all three: every pair's arrow points
5993: the way the signal flows, left = producer or entry point, right = consumer,
5994: every right side fed exactly once.
