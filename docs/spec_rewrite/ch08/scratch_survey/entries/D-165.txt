5619: ### D-165 — Split output-stage returns into public `y` and private `w`
5620: 
5621: **Status.** superseded → [D-194][d-194]
5622: 
5623: **Position.** Every output stage returns either `y::NamedTuple` (ports only) or
5624: `(y, w)::Tuple{NamedTuple, NamedTuple}`; a `nothing` in either slot is a probe
5625: error; an empty `y = (;)` is legal, so port-less stages fall out of the general
5626: law (stages are discovered by method existence, membership is a partition of
5627: declared ports that may be empty) — a stage producing neither ports nor `w` is
5628: a dead-stage build error (`DeadStage`).
5629: 
5630: **Spec.** [§5.2][s5-2], [§5.4][s5-4], [§7.5][s7-5], [§11.2][s11-2], [§8.3][s8-3], [§9.5][s9-5], [§9.7][s9-7], [§13.2][s13-2], [§14.4][s14-4]
5631: 
5632: **Rationale.** `w` carries the component's private intermediates: an
5633: `isbits`-leaf NamedTuple, never a table cell.
5634: 
5635: **One-hop law**: `h_x`'s `w` flows to `h_xu` if defined, otherwise to the
5636: downstream set (`f`, guards, handlers); `h_xu`'s `w` flows to the downstream
5637: set; nothing flows implicitly — forwarding across hops is an explicit re-return
5638: (`(y, (; w..., extra))`). Symmetric on the discrete tier (`h_z` → `h_zu` →
5639: `g`), stated once.
5640: 
5641: `w` joins the closed bundle name sets of `h_xu`, `f`, guards, handlers, `h_zu`,
5642: `g`; presence in a bundle follows the producing stage's probed return (bare-`y`
5643: producer ⇒ no `w` key ⇒ the [§13.2][s13-2] framing diagnostic on a consumer that
5644: destructures it).
5645: 
5646: `w` is **SSA-passed inside fused executor passes** (the step fuses sweep + `f`;
5647: each event round fuses sweep + guards + fired handlers) and never persisted —
5648: freshness by construction, recomputation cost zero, and the executor commits to
5649: round-fusion as a design constraint.
5650: 
5651: `w` types are probe-observed; the probe validates the NamedTuple form and
5652: consumer reads against the observed field set (did-you-mean from actual fields,
5653: weaker than declaration-backed but located).
5654: 
5655: `w` joins the branch-shape rule and the **always-on check at the nominal
5656: activation**: expected = the nominal probe's observed type, one baked `isa`
5657: beside the `y` test — folds to zero instructions when stable, and converts the
5658: unintended-branch-divergence class (which otherwise surfaces only as
5659: allocations in testing) into a loud, located, field-naming error at first
5660: divergent execution, with blame text honestly citing the probe ("expected what
5661: the nominal probe observed"), complementing [§7.5][s7-5]'s canary (detection) with
5662: localization.
5663: 
5664: **Non-nominal activations run no `w` check**: with no declaration for a
5665: branch-independent anchor and no store to embed into, a strict probe-observed
5666: check there false-positives on the legal constant-branch idiom
5667: (probe-branch-dependent expectations — the one-probe-point argument), while
5668: correctness needs no guard (a `Float64` in `w` under `Dual` is an honest
5669: zero-partial constant by the embedding guarantee; downstream promotion is
5670: exact).
5671: 
5672: `local_types` is deleted with its satellites: stage membership derives over
5673: `output_types` alone; `ContractNameCollision` retired; `UndeclaredReturnField`
5674: candidates = `output_types`; `get_local` retired from the [§14.4][s14-4] selector family
5675: and [§11.2][s11-2]'s read bindings — the inspection path for intermediates is
5676: *promote to output* (FlightCore precedent: intermediates were only ever
5677: inspected by inclusion in the `Model` output); local cells leave the [§9.7][s9-7]
5678: store; [§8.3][s8-3] visibility becomes: declared in `output_types` = public, returned
5679: in `w` = private **by construction** (nothing to connect, list or filter);
5680: walkthrough 5 rewritten.
5681: 
5682: Guidance, not law: a `w`-only `h_x` is redundant when `h_xu` exists (fold it in
5683: — both run once per sweep); it is the honest spelling of `u`-independent shared
5684: intermediates when no `h_xu` exists.
5685: 
5686: **Rejected.**
5687: - *Walking the nominal-observed type to synthesize non-nominal expectations:*
5688:   rejected as machinery kept alive for a check that catches nothing the nominal
5689:   one misses.
5690: - *`local_types` status quo ([D-034][d-034]/[D-055][d-055]):* declaration + table cells +
5691:   presentational filtering for values that were never interface; threading is
5692:   structurally private and cheaper, and per-activation probe observation
5693:   dissolves the dropped-partials objection that rightly killed observation
5694:   authority for *pinned* locals.
5695: - *Pass-through on bare `y`:* the one implicit flow in the design, plus a
5696:   bare-`y`-vs-`(y, nothing)` subtlety needing a didactic paragraph.
5697: - *The `(y, nothing)` chain-terminate form:* no demonstrated customer; extra
5698:   fields downstream are harmless to a destructuring consumer.
5699: - *Opaque `isbits` `w`:* no name-shaped diagnostics.
5700: - *Persisted `w` slots / table cells for `w`:* a cell needs a fixed
5701:   per-activation type, and with `local_types` gone there are only bad sources —
5702:   probe-observed types detonate branch-dependently, the
5703:   `output_types`-inference flaw re-imported; a declaration resurrects what is
5704:   being deleted; an anchor+walk keeps the output-side walk alive for private
5705:   values. SSA-passing dissolves the question: a flowing value has no type
5706:   contract to violate, promotion handles mixed branches exactly — this is what
5707:   makes probe-observation sound here where [D-034][d-034]/[D-055][d-055] rightly rejected it for
5708:   cells. Also: staleness class, store traffic for register-resident values, `w`
5709:   names re-entering the cell namespace, and the loss of "every cell is a
5710:   connectable port". The forfeited snapshot visibility is covered by
5711:   promote-to-output, with a debug-mode SSA capture recorded as the cell-free
5712:   door.
5713: - *Restricting port-less stages to `h_xu`:* the one-hop law routes a sole
5714:   `h_x`'s `w` directly downstream; with no `h_xu` defined, port-less `h_x` is
5715:   the spelling whose no-`u` view set honestly declares the intermediates
5716:   `u`-independent.
