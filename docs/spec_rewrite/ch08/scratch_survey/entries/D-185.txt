6537: ### D-185 — Adopt the phased, two-form sample-time declaration
6538: 
6539: **Status.** ratified
6540: 
6541: **Position.** Sample-time declaration gains phases and becomes two-form —
6542: `sample_time_proposal.md` adopted (the proposal remains the worked companion):
6543: a `sample_times` entry (the method renamed from `rates`, faithfulness over
6544: brevity) declares one (period, phase) pair as an explicit wrapper type naming
6545: the unit system — `Relative(K, Φ = 0)` in scope ticks (`K ≥ 1`, `0 ≤ Φ < K`),
6546: `Absolute(q, τ = 0)` in exact rational seconds (`T = period(q) > 0`, `0 ≤ τ <
6547: T`, `q` a `Period`/`Hz` quantity normalized to its rational period at
6548: construction; float arguments throw a teaching error naming the exact spelling)
6549: — the wrappers the whole value vocabulary, an unlisted discrete child
6550: defaulting to `Relative(1)`, validation Stratum A's with path attribution and
6551: the constructors plain data carriers.
6552: 
6553: **Spec.** [§10.5][s10-5], [§8.7][s8-7], [§9.1][s9-1], [§9.7][s9-7], [§13.1][s13-1], [§14.5][s14-5], [§14.8][s14-8]
6554: 
6555: **Rationale.** Composition: multipliers multiplicative, phases affine (`D =
6556: K·Dₛ`, `Φ = Φₛ + φ·Dₛ`), preserving the canonical residue `0 ≤ Φ < D` with no
6557: normalization pass, all scoping still compiling to one `(D, Φ)` pair per
6558: discrete component; the boundary gate is `(idx − Φ) % D == 0` — one gate for
6559: all three tick-sensitive blocks, due-ness per component per boundary never per
6560: stage, `t*` emptiness remaining arity selection (no sentinel index fails every
6561: gate); boundary zero refines from "everything due" to "everything with `Φ =
6562: 0`", implemented by nothing — the ordinary gate at index 0 under the residue
6563: invariant — an offset component holding its probe-populated cells until its
6564: first tick at `Φ·Δt_base` ([§14.5][s14-5]'s sweep bullet and [§14.8][s14-8]'s committed-residual
6565: read-back each carry the caveat); `Δt` semantics explicitly unchanged
6566: (`D·Δt_base`; a phase shifts firing instants, never the period); relative
6567: phases never refine the base grid and cannot leave the scope grid, and `K = 1`
6568: admits no stagger — same-rate siblings stagger one level down, the scope
6569: declared at twice their rate.
6570: 
6571: Annotation (2026-10-02): amended by [D-205][d-205]. Every discrete output stage
6572: publishes at boundary zero, so no offset component holds probe-populated
6573: cells. The gate composition and the residue invariant stand.
6574: 
6575: **Rejected.**
6576: - *Bare-value sugar behind a normalization function (`ratespec`: bare `Int` ⇒
6577:   `Relative`, bare quantity ⇒ `Absolute`):* implicit form inference; the
6578:   form stays visible at every declaration site, the common case handled by
6579:   the unlisted-child default instead.
6580: - *Floats in periods or offsets:* GCD derivation over floats is ill-defined;
6581:   `Rational{Int}` fields make exactness structural.
6582: - *Constructor-side range validation:* instant REPL feedback, but fails a
6583:   `sample_times` body's *evaluation* with a raw exception against [§13.1][s13-1]'s
6584:   collect-the-checks policy.
6585: - *Materialized due sets:* a precomputed hyperperiod table (the lcm grows
6586:   multiplicatively where the gcd-derived grid grows slowly, and it converts two
6587:   arithmetic ops into a dynamically-indexed load of runtime data) and a
6588:   per-frame recomputed mask (mutable state threaded through the sweep to
6589:   replace a subtraction and a remainder with a load) — both lose to the pure
6590:   gate, which also generalizes to the extensions charter's triggered updates
6591:   where a table does not.
6592: - *`RelativeRate`/`AbsoluteRate`:* clash-safer exports, worse at the
6593:   declaration site; the recorded fallback if clashes bite.
