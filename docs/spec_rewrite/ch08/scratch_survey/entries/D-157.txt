5404: ### D-157 — Check for nonfinite `x` immediately after integrate
5405: 
5406: **Status.** ratified
5407: 
5408: **Position.** **The nonfinite-`x` check is the boundary's first act —
5409: immediately after integrate, before `project` and the boundary sweep** — so a
5410: diverged component is named by `NonfiniteState` before its NaN reaches an
5411: innocent downstream component and surfaces as a lookup-table `DomainError`
5412: ([§8.4][s8-4]'s error-locality inversion, otherwise reintroduced at runtime); **`ẋ`
5413: does not participate, with the reason stated**: any nonfinite `ẋ` contaminates
5414: the same state block's step result within that very step, so the `x` check at
5415: the next boundary is the same detection with identical component attribution,
5416: and `ẋ` buffers are integrator scratch, not boundary-consistent ([D-098][d-098]'s
5417: source axis).
5418: 
5419: **Spec.** [§8.4][s8-4], [§9.5][s9-5], [§13.4][s13-4]
5420: 
5421: **Rationale.** A round-5 kernel dry-run finding (finding 13).
5422: 
5423: **Rejected.**
5424: - *Checking after the event phase or after `g`:* sweep and guards run on the
5425:   NaN state first — the locality inversion the check exists to prevent.
5426: - *Adding an `ẋ` sweep:* redundant by the contamination argument, and it would
5427:   bless reading integrator scratch against [D-098][d-098]'s source axis.
