6306: ### D-178 — Reaffirm component-side rejections against the periphery's new idiom
6307: 
6308: **Status.** ratified
6309: 
6310: **Position.** The component side is reaffirmed against the periphery's new
6311: idiom — no spec change ([D-177][d-177]'s clarity-supertype argument explicitly does
6312: *not* transfer).
6313: 
6314: **Spec.** [§8.1][s8-1], [§8.5][s8-5]
6315: 
6316: **Rationale.** Tier supertypes `ContinuousComponent`/`DiscreteComponent` stay
6317: rejected, because the single-inheritance slot of a concrete leaf is owned by
6318: the domain hierarchies (`AbstractAircraft`, engine families) — threading domain
6319: abstractions under tier roots forecloses cross-tier substitution in one slot (a
6320: continuous PID and a discrete compensator in the same avionics slot) and
6321: assemblies in domain slots (an assembly is tierless) — and because a nominal
6322: tier would be a **third copy of a twice-declared, cross-checked fact**
6323: (`f`-vs-`g` plus the [§8.5][s8-5] signature arities, `TierSignatureMismatch`), which
6324: is [D-173][d-173]'s `is_discrete` rejection restated one level up: the periphery's
6325: traits add information no method carries, a tier supertype would add none.
6326: **Value fallbacks** on the component root (`init_x(::AbstractComponent) =
6327: nothing`, `input_types(::ContinuousComponent, ::Type{T}) = (;)`) stay rejected
6328: on a sharper doctrine than convenience: they would make every component
6329: "declare" everything, so class and feature presence stop being readable from
6330: the declaration set ([§8.5][s8-5]'s class-by-declaration-shape), they silence both
6331: [D-164][d-164]'s declares-nothing build error and [§8.1][s8-1]'s shadowing defense — the two
6332: checks that catch the silent-degradation family — and they reinstate
6333: sentinel-meaning returns (`nothing` = no state) that the declaration vocabulary
6334: refuses. Doctrine recorded in one line: **error fallbacks are interface
6335: machinery, value fallbacks are semantics**, and semantics-by-default is banned
6336: where absence means nonexistence. Residual, recorded rather than remedied:
6337: partial local-scope shadowing of *optional* feature declarations (`events`,
6338: `workspace`) still builds silently with fewer features, since presence is the
6339: whole signal there and no trait declares them; if it ever bites, the remedy is
6340: build-time legibility of the declaration set (printing what a component was
6341: read as declaring), never per-feature intent Bools, which would be the
6342: boilerplate-on-every-leaf outcome [D-039][d-039], [D-173][d-173] and this row all refuse.
6343: 
6344: **Rejected.** The rejected alternatives are this row's subject:
6345: - *Tier supertypes* `ContinuousComponent`/`DiscreteComponent`.
6346: - *A nominal `is_discrete`-style tier marker* ([D-173][d-173], upheld).
6347: - *Value fallbacks on `AbstractComponent`'s declaration generics.*
6348: - *Per-feature intent Bools for the optional declarations.*
