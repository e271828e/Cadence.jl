1007: ### D-033 — Declaration inventory: by-value, by-type, by-allocation conventions
1008: 
1009: **Status.** ratified
1010: 
1011: **Position.** Declaration inventory: `init_*` by value (type derived — nothing
1012: to drift); `input_types(::C)` bare NamedTuple of types at `Float64` faces,
1013: wiring check `producer_face <: entry` ([D-078][d-078]);
1014: `output_types(::C)`/`local_types(::C)` plain concrete nominal declarations on
1015: both tiers, per-activation cell types from the framework leaf walk ([D-079][d-079]);
1016: `workspace` registered by allocation ([D-077][d-077]); `events(::C)` ordered + per-event
1017: `localize` flag (`true` = Tier 2, default `false` = Tier 1); stage membership
1018: derived (inputless `h_x` probes first, remainder is stage 2), no stage tags.
1019: 
1020: **Spec.** [§4.2][s4-2], [§8.1][s8-1], [§8.2][s8-2]
1021: 
1022: **Rationale.** The inventory is self-classifying by convention: by value
1023: `init_*`, by type `*_types`, by allocation `workspace` ([D-076][d-076]). Contract
1024: declarations are functions of the component's *type*, parameters included
1025: (`SumJunction{W,N}`, `Or{N}`), never of field values — `workspace` explicitly
1026: exempt (by-allocation, [D-077][d-077]) — because [§9.7][s9-7]'s entry typing derives the bundle
1027: key set from the type; a rule authors keep, not a check the build can run
1028: ([§8.1][s8-1]).
1029: 
1030: **Rejected.**
1031: - *Superseded position — `outputs(::C, ::Type{T})` on continuous components
1032:   with plain `outputs(::C)` on discrete as the tier-in-signature marker (the
1033:   earlier design of record):* functions of the sweep scalar, literal `Float64`
1034:   = deliberate non-participation; retired with the `T`-signature ([D-079][d-079]).
1035: - *Exact-equality wiring check:* relaxed to subtype, equality the concrete
1036:   degenerate ([D-078][d-078]).
1037: - *The names `inputs`/`outputs`/`locals`:* renamed for self-classification by
1038:   convention and to dissolve the `inputs` vs `input_faces` ambiguity
1039:   ([D-076][d-076]).
1040: - *Under-the-hood `Float64→T` substitution:* reflection-heavy; cannot
1041:   distinguish honest `Float64`s.
1042: - *Sentinel eltype tokens:* same machinery, worse spelling.
1043: - *Subtype/pattern matching on the output side:* motivating case dissolved by
1044:   `T`; abstract slots break concrete typing.
1045: - *Names-only input contracts:* lose wiring-time type errors and standalone
1046:   checkability.
1047: - *Per-stage output lists:* stage membership is internal, [§4.2][s4-2].
